# Grocery Unit Price Compare

A phone web app that compares unit prices between two grocery stores (Dollarama and Farm Boy).
Point the camera at a shelf price tag: the app reads the price and size on the phone (Tesseract.js OCR),
works out which of 36 tracked items the tag is for, and shows which store is cheaper per 100 g or per litre.

- Runs entirely in the browser; prices stay on the phone.
- Add `#demo` to the address for a demo with sample scans.
